T7 - Evaluación de un Enlace LoRa Punto a Punto

Este proyecto implementa una red LoRa punto a punto utilizando dos módulos Heltec WiFi LoRa 32 V3 para evaluar el impacto del Spreading Factor (SF) sobre el desempeño del enlace inalámbrico.

Se realizaron pruebas experimentales a diferentes distancias, registrando métricas como RSSI, SNR y PDR (Packet Delivery Ratio), con el fin de analizar la relación entre alcance, robustez y calidad de la comunicación.

Estructura del proyecto
TX/: Código del nodo transmisor.
RX/: Código del nodo receptor.
Python/: Scripts para procesamiento de datos y generación de gráficas.
CSV/: Datos experimentales recolectados.
Graficas/: Resultados visuales obtenidos a partir de los datos.
Hardware
2 × Heltec WiFi LoRa 32 V3
